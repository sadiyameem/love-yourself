# Love Yourself

# Description
- This project is meant to encourage self-love and positivity. When the user clicks on the button, a heartbeat sound is played, the heart will begin to pulse and confetti will appear each time the button is click for a surprise. And when the user clicks on the background hearts will appear and users can know why self-love is important by the click of the generator.

# Features
- Heart with pulse
- Start button
- Heartbeat sound
- Confetti animation
- Heart animation
- Self-Love generator
