# Love Yourself

# Description
- This project is meant to encourage self-love and positivity. When the user clicks on the button, a heartbeat sound is played, the heart will begin to pulse and confetti will appear each time the button is click for a surprise.

# Features
- Heart with pulse
- Start button
- Heartbeat sound
- Confetti animation
